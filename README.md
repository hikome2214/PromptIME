# PromptIME 0.1.0-preview

Windows用のプロンプト入力補助です。登録した「よみ」を2文字以上入力すると候補が出て、Tabで本文を貼り付けます。↑↓で選択しEnterで確定、Escで候補を閉じられます。

## 起動

1. https://www.autohotkey.com/ からAutoHotkey v2をインストールします。
2. ZIP全体を、書き込みできる専用フォルダへ展開します。
3. PromptIME.ahkをダブルクリックします。管理者として起動する必要はありません。
4. 通知領域のアイコンを右クリックし「プロンプト登録画面を開く」を選びます。

AutoHotkey本体は同梱していません。実行ファイル版ではなくスクリプト版です。Program Filesなど書き込みが制限される場所を避けてください。

## 登録と使い方

「よみ」「プロンプト本文」を入力し、必要ならジャンルと添付を設定して「新規登録」を押します。一覧から選ぶと更新・削除ができます。ジャンルは自由入力でき、検索や種類・ジャンルの絞り込みにも対応します。

登録画面を閉じて入力先に戻り、よみを2文字以上入力してください。最初はメモ帳などで、サンプルの「ようやく」を試してください。送信操作は手動です。

添付は貼り付け先がファイル貼り付けに対応している場合のみ使えます。貼り付け操作でアップロードが始まるサービスもあるため、添付内容を事前に確認してください。サービスごとの添付動作・日本語入力の相性は未検証です。

## 保存場所と更新

初回起動時にsamplesのサンプルをdataフォルダへコピーします。登録内容はdata/prompts.txt、添付先はdata/attachments.ini、分類はdata/genres.iniに保存されます。既存ファイルは初期化で上書きしません。

更新前にアプリを終了してdataを非公開の場所へバックアップし、公開ファイルのみ入れ替えてください。終了は通知領域のメニューから行います。自動起動の設定は行いません。

## 公開・再配布するとき

dataは個人データです。公開・再配布しないでください。自分の添付ファイル、画面写真、ログやバックアップも追加しないでください。samplesは公開可能な例だけを置く場所です。将来の変更でも再点検が必要です。

.gitignoreは公開するファイルを限定する方式です。すでに追跡されたファイルやgit add -fによる強制追加、手作業で作るZIPの内容までは保護しません。

APIキー・AIサービスの契約はアプリ自体には不要です。入力先のサービスの利用条件は各サービスに従います。詳細はPRIVACY.mdをご覧ください。
